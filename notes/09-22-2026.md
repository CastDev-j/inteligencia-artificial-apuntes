# Machine learning

Rama de la IA en la que la máquina **aprende de los datos** en vez de programarse con reglas. Mientras más ejemplos ve, mejor se vuelve.

En vez de codificar las reglas, le mostramos **ejemplos con su respuesta** y la máquina deduce las reglas sola:

```
Programación:       Datos + Reglas → Respuestas
Machine Learning:   Datos + Respuestas → Reglas (el modelo)
```

Esto surgió porque en los sistemas expertos resultaba muy caro/pesado extraer el conocimiento de un experto humano.

## Las 4 tareas principales del ML

Son las preguntas que un modelo puede responder:

| Tarea | ¿Qué hace? | ¿Qué responde? | Ejemplo |
|---|---|---|---|
| **Clasificación** | Separa los datos en categorías | ¿De qué grupo es? | Spam o no, perro o gato |
| **Regresión** | Predice un valor numérico | ¿Cuánto vale? | Precio de una casa, temperatura |
| **Segmentación (clustering)** | Agrupa por parecidos, sin respuestas previas | ¿Quién se parece a quién? | Agrupar clientes por hábitos |
| **Asociación** | Encuentra relaciones entre elementos | ¿Qué viene junto con qué? | Quien compra pan suele comprar leche |

## Tipos de aprendizaje

Son las **formas de aprender** que se usan para dichas tareas:

| Tipo | Idea | Tareas que resuelve | Ejemplo |
|---|---|---|---|
| **Supervisado** | Aprende con ejemplos que ya tienen la respuesta | Clasificación y regresión | Spam, precio de casa |
| **No supervisado** | Solo datos; la máquina busca patrones por sí sola | Segmentación y asociación | Agrupar clientes |
| **Por refuerzo** | Actúa, recibe recompensas/castigos y aprende por prueba y error | — (curso aparte) | AlphaGo, videojuegos |

> **Inducción vs transducción.** Normalmente el ML es **inductivo**: de casos particulares deduce una regla general (el modelo). La **transducción** es lo contrario: dado un conjunto de ejemplos de prueba específico, predice la respuesta de *esos* casos **sin generalizar** a un modelo que sirva para cualquier dato. Es un puente entre supervisado y no supervisado (usa datos etiquetados + no etiquetados).

```
Inducción:     ejemplos → regla general → respuestas para CUALQUIER dato
Transducción:  ejemplos + esos datos de prueba → respuestas SOLO para esos datos
```

## Flujo de un proyecto

```
Datos → limpiarlos → dividir (entrenar/prueba) → entrenar → evaluar → usar
```

- **Entrenar:** el modelo aprende con una parte de los datos.
- **Evaluar:** se prueba con datos que **nunca vio**, para saber si de verdad aprendió.

> Si se evalúa con los mismos datos de entrenamiento, el modelo "memoriza" y la nota es trampa.

## Conceptos útiles

| Concepto | Significado |
|---|---|
| **Característica (feature)** | Dato de entrada (área, habitaciones…) |
| **Etiqueta (label)** | La respuesta correcta (el precio) |
| **Modelo** | Lo que queda después de aprender |
| **Entrenamiento / Inferencia** | Aprender vs. aplicar lo aprendido |

---

## Sobreajuste: el error más común

| Error | Qué pasa | Analogía |
|---|---|---|
| **Sobreajuste (overfitting)** | Memoriza los ejemplos, pero falla con datos nuevos | Estudiar de memoria sin entender |
| **Subajuste (underfitting)** | Es tan simple que no capta el patrón | No estudiar nada |

> La meta es el punto medio: **entender el patrón sin memorizar los ejemplos**.

## k vecinos más próximos (k-NN)

Una de las formas más simples de clasificar (o predecir): **"dime con quién andas y te diré quién eres"**.

**Idea**

- Los datos se representan como **puntos** según sus características.
- Para clasificar uno nuevo, se buscan los **k vecinos más cercanos**.
- **Clasificación:** voto por mayoría → la clase de la mayoría de esos vecinos.
- **Regresión:** promedio del valor de esos vecinos.

```
k = 3 → los 3 puntos más cercanos son: perro, perro, gato → voto mayoritario = PERRO
```

**Características**

- **Lazy learning:** no entrena un modelo; guarda los datos y decide al predecir.
- Solo necesita una **medida de distancia** (p. ej. euclidiana).
- Depende del valor de **k**: pequeño = sensible al ruido; grande = más suave pero pierde detalle.

| ✅ Ventajas | ❌ Desventajas |
|---|---|
| Simple de entender | Lento con muchos datos (mide todas las distancias) |
| No entrena, solo guarda | Sensible a características irrelevantes |
| Sirve para clasificar y regresionar | El valor de k afecta el resultado |

## Redes neuronales artificiales (RNA)

Inspiradas en el cerebro: un montón de **neuronas artificiales conectadas** que juntas aprenden patrones muy complejos.

**Idea**

- Cada **neurona** recibe entradas, las multiplica por **pesos** y dispara una salida (activación).
- Los **pesos se ajustan en el entrenamiento**: la red "prueba, compara con la respuesta correcta y corrige" (*backpropagation*).
- Se organizan en **capas**: entrada → capas ocultas → salida.

```
entrada → [neurona] → [neurona] → salida
                  ↓
      capa oculta: reconoce patrones
```

**Características**

- **Deep learning:** una red con **muchas capas ocultas** aprende niveles (bordes → formas → objetos…).
- Resuelven **clasificación, regresión y agrupación**; destacan en **imágenes, texto y voz**.
- Potentes pero **caja negra** (difícil explicar sus decisiones) y requieren **muchos datos y cómputo**.

| ✅ Ventajas | ❌ Desventajas |
|---|---|
| Aprenden patrones muy complejos | Necesitan muchos datos |
| Excelentes en imágenes, texto y voz | Difícil de explicar (caja negra) |
| Sirven para casi todas las tareas | Costosas de entrenar (GPU) |

## Clasificador Naive Bayes

Clasificador basado en **probabilidades**: calcula qué categoría es *más probable* dadas las características, y elige esa.

### Idea

- Parte del **teorema de Bayes**: la probabilidad de una clase dados los datos se puede calcular a partir de la probabilidad de los datos dada la clase.

```
P(clase | datos) = P(datos | clase) · P(clase) / P(datos)
```

- Se llama **naive (ingenuo)** porque asume que las características son **independientes entre sí**, lo cual casi nunca es cierto… pero funciona sorprendentemente bien.

### Ejemplo

```
"El pasto está mojado, ¿llovió o regaron?"
P(llovió | mojado) vs P(regaron | mojado) → gana la más alta
```

### Características

- **Rápido y sencillo:** aprende muy poco (solo cuenta frecuencias de los datos).
- Ideal para **texto**: filtro de spam, análisis de sentimiento, clasificación de noticias.
- Funciona con **pocos datos** y es muy escalable.

| ✅ Ventajas | ❌ Desventajas |
|---|---|
| Muy rápido y ligero | Asume independencia de características (simplificación) |
| Excelente para texto (spam, sentimiento) | Pierde relación entre características |
| Funciona con pocos datos | Si falta una combinación, la probabilidad se cae (0) |

## Dónde se usa

Reconocimiento de imágenes/voz · recomendaciones (Netflix, Spotify) · fraude bancario · chat/IA generativa · medicina (diagnóstico por imagen).

## En resumen

ML = **aprender de ejemplos** en lugar de programar reglas. Se resume en **4 tareas** (clasificar, regresar, segmentar y asociar), aprendidas de forma **supervisada o no supervisada**. Superó la limitación de los sistemas expertos (extraer conocimiento), a cambio de necesitar **buenos datos** y **poder de cómputo**, y de ser una **caja negra** (difícil de explicar).

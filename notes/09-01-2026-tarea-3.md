# Tarea 3: Modus Ponens y Modus Tollens

Son las dos **reglas de inferencia** más básicas de la lógica proposicional. Permiten derivar conclusiones a partir de premisas válidas.

---

## Modus Ponens

**Afirmando el antecedente** → se afirma el consecuente.

```
Si P entonces Q
P
─────────
Q
```

| Elemento | Definición |
|---|---|
| **P → Q** | Premisa condicional |
| **P** | Antecedente (se cumple) |
| **Q** | Consecuente (se concluye) |

### En Prolog

El modus ponens es la base de las **reglas Prolog**:

```prolog
% Si llueve, entonces el suelo está mojado
mojado(suelo) :- llueve.

% Hecho: está lloviendo
llueve.

% Consulta: ¿el suelo está mojado?
?- mojado(suelo).
true.
```

---

## Modus Tollens

**Negando el consecuente** → se niega el antecedente.

```
Si P entonces Q
no Q
─────────
no P
```

| Elemento | Definición |
|---|---|
| **P → Q** | Premisa condicional |
| **¬Q** | Consecuente negado (no se cumple) |
| **¬P** | Antecedente negado (se concluye) |

### En Prolog

```prolog
% Si tiene fiebre, entonces está enfermo
enfermo(ana) :- fiebre(ana).

% Consulta: ¿ana no tiene fiebre? (negando el consecuente)
?- \+ fiebre(ana).
true.
% Se infiere: ana no está enferma (si no hay fiebre)
```

---

## Comparación

| | Modus Ponens | Modus Tollens |
|---|---|---|
| **Movimiento** | Afirma antecedente → consecuente | Niega consecuente → antecedente |
| **Sentido** | Progresivo (hacia adelante) | Regresivo (hacia atrás) |
| **Función** | Confirmar la regla | Refutar la regla |
| **Equivalente en SE** | Encadenamiento hacia adelante | Encadenamiento hacia atrás |
| **Ejemplo** | Llueve → está mojado | No está mojado → no llovió |

---

## Falacias relacionadas (cuidado con estas)

| Falacia | Error |
|---|---|
| **Afirmar el consecuente** | Si P→Q y Q, concluir P (es inválido) |
| **Negar el antecedente** | Si P→Q y ¬P, concluir ¬Q (es inválido) |

> La diferencia clave: modus ponens y tollens son **válidos**; las dos falacias anteriores no lo son.
